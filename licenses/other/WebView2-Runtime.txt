Microsoft Edge WebView2 Runtime

The Atlasaga installer embeds the Microsoft Edge WebView2 Evergreen
Bootstrapper (MicrosoftEdgeWebview2Setup.exe), which Microsoft allows
applications to redistribute. When the WebView2 Runtime is missing, the
bootstrapper downloads and installs it from Microsoft. The WebView2 Runtime
and the bootstrapper are Microsoft software, licensed by Microsoft under
its own terms, not by Atlasaga:

  https://developer.microsoft.com/microsoft-edge/webview2/
  https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution
